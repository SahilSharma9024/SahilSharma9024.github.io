Description

An automation system that keeps social media audiences informed about the latest developments in artificial intelligence. It monitors trending topics, writes concise summaries of news articles, and shares them across Twitter, LinkedIn and WhatsApp — without anyone touching a keyboard.

Highlights

  • Automated sourcing: finds the most relevant AI news links for a given topic.
  • AI summaries: turns long articles into short, engaging snippets using the Google Gemini API.
  • Multi-platform: posts to Twitter, LinkedIn and WhatsApp in a single workflow.
  • Smooth login: uses Chrome profiles to stay authenticated and skip manual steps.
  • Logging: writes every post to a local file for record-keeping.

Workflow

  1. Search APIs find the latest URLs for trending AI news.
  2. AI generates a short, catchy summary for each article.
  3. Selenium opens a pre-logged-in Chrome instance.
  4. The tool posts automatically to Twitter and LinkedIn feeds.
  5. Snippets are sent to specific WhatsApp groups from a list.

Tech Stack

Python Selenium Google Gemini API Serper API SerpAPI CSV / MD / TXT

My Role

Built the complete pipeline — from news discovery and AI integration through to browser automation and multi-platform posting.

Description

A personalised music recommendation system where users pick their preferred language, mood and number of songs. It surfaces top tracks from a 90,000+ song dataset, plays them directly on Spotify, offers a random-play option for discovery, and quietly learns from user feedback to sharpen future recommendations.

Highlights

  • Filtering & ranking: built over a dataset of 90,000+ songs, matched on metadata like genre, tempo and tags.
  • Mood- and language-driven: recommendation logic tuned for personalised results rather than generic popularity.
  • Spotify playback: every recommended track plays directly through the Spotify API.
  • Random discovery: a "Play Random Song" option pulls from the recommended list for effortless exploration.
  • Feedback loop: liked and disliked tracks are logged to improve recommendation quality over time.

Workflow

  1. User selects language, mood and how many recommendations they want.
  2. The system filters the 90,000+ track dataset on language and mood.
  3. Top n songs are ranked by relevance and popularity, then listed.
  4. Each track plays on Spotify — or one is picked at random.
  5. Likes and dislikes are logged to personalise future suggestions.

Tech Stack

Python Pandas Flask Spotify API

My Role

Designed and built the full pipeline: user selection → filtering → recommendation ranking → Spotify playback → feedback logging.

Description

A database-driven system for managing student academic records — students, subjects, marks and result processing — with role-based access control. It replaces manual result handling with a secure, scalable workflow built on a properly normalised schema.

Highlights

  • Normalised schema: designed a relational database for managing students, subjects and results.
  • Role-based authentication: separate Admin and Teacher access paths, with inactive users blocked rather than deleted.
  • Management modules: student records, subject handling and marks entry, each scoped to the right role.
  • Automated results: total, percentage, grade and pass/fail computed rather than entered by hand.
  • Data integrity: validation against maximum marks and prevention of duplicate entries.

Workflow

  1. A user signs in; credentials are validated and their role and active status checked before any dashboard loads.
  2. Admins manage the student roster and subject catalogue, including maximum and passing marks per subject.
  3. Teachers enter marks per student per subject, validated against the subject maximum and guarded against duplicates.
  4. The system computes totals, percentage, grade and pass/fail status from the recorded marks.
  5. Final results are surfaced to whichever roles are authorised to see them.

Tech Stack

Python MySQL Flask

My Role

Designed the database schema and built the authentication, management and result computation layers — keeping UI, logic and data cleanly separated.
