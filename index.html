Description

SnippetsAI is an end-to-end automation solution designed to keep social media audiences updated with the latest developments in Artificial Intelligence. Instead of manually searching for news, writing posts, and publishing them across different platforms, the system performs the entire process automatically.

It continuously searches for trending AI news, generates short and engaging summaries using Google's Gemini AI, and publishes the content on Twitter, LinkedIn, and WhatsApp. This reduces manual effort while ensuring that followers receive timely and informative updates.

Highlights

  • Automated News Discovery: The system automatically searches the internet for the latest and most relevant Artificial Intelligence news. It uses Serper API and SerpAPI to identify trending topics and collect high-quality news article links based on predefined keywords.
  • AI-Powered News Summaries: Instead of sharing lengthy articles, the system uses the Google Gemini API to generate concise, easy-to-read summaries. Each summary is written in a clear and engaging style that is suitable for social media platforms.
  • Multi-Platform Posting: A single workflow publishes the generated content across multiple social media platforms, including:
    • Twitter (X)
    • LinkedIn
    • WhatsApp Groups
    This ensures consistent communication without requiring separate posting for each platform.
  • Automated Browser Login: The project uses Selenium with existing Chrome user profiles. Since the browser profile is already logged into the required social media accounts, the automation can post directly without asking for usernames, passwords, or repeated authentication.
  • Activity Logging: Every generated summary and published post is saved locally in CSV, Markdown, or text files. These logs help maintain records of previously shared content and make it easier to review or audit the automation process.

Workflow

  1. News Collection: The system searches for trending AI topics using Serper API and SerpAPI. It gathers the latest article URLs from reliable online sources.
  2. Content Generation: The collected article links are sent to the Google Gemini API, which analyzes the content and creates short, engaging summaries suitable for social media.
  3. Browser Automation: Selenium launches a Chrome browser using a pre-authenticated user profile, allowing the automation to access social media accounts without manual login.
  4. Social Media Publishing: The generated summaries are automatically posted to Twitter (X) and LinkedIn with appropriate formatting.
  5. WhatsApp Distribution: The same summaries are sent to selected WhatsApp groups, enabling instant sharing with communities or teams.
  6. Record Keeping: After successful posting, the system stores details of every post in local CSV, Markdown, or text files for future reference.

Tech Stack

Python Selenium Google Gemini API Serper API SerpAPI CSV / MD / TXT

My Role

I independently designed and developed the complete automation pipeline. My responsibilities included:

  • Integrating Serper API and SerpAPI for automated AI news discovery.
  • Connecting the Google Gemini API to generate high-quality news summaries.
  • Building Selenium-based browser automation for Twitter (X), LinkedIn, and WhatsApp.
  • Configuring Chrome profile management for seamless authenticated sessions.
  • Implementing automated logging and record management.
  • Testing, debugging, and optimizing the complete workflow to ensure reliable end-to-end automation.

Description

FeelTheBeat is a Personalised Music Playlist Builder — a serverless music assistant that curates your listening automatically. It tracks the songs you have on repeat, saves them to your library, builds a fresh recommendation playlist every week, and delivers an AI-written summary of your week in music to your phone over WhatsApp — running entirely on a schedule, with no server and no manual step.

The same codebase drives both Spotify and YouTube Music. Switching between them is a one-line configuration change.

Highlights

  • Platform-agnostic design: Spotify and YouTube Music are interchangeable backends behind a shared five-function contract, so the core logic is written once and the service can be swapped with a single config value.
  • Automatic library curation: detects "heavy rotation" tracks using a rolling window over recent play history and saves them, skipping anything already in the library so runs stay idempotent.
  • Weekly discovery playlist: rebuilds a recommendation playlist each week, seeded by what you are actually listening to now rather than your all-time taste.
  • AI-written summaries: Google Gemini turns raw listening data into a personal weekly wrap-up, with a deterministic fallback so a message always goes out even if the AI call fails.
  • WhatsApp delivery: sends via Twilio, using approved Content Templates to bypass WhatsApp's 24-hour messaging window and guarantee unattended weekly delivery.
  • Configuration-driven scheduling: run day, hour and timezone live in the application config, not in CI YAML — retiming the bot requires no infrastructure changes.
  • Zero-cost deployment: runs on GitHub Actions cron with no server, database or hosting bill.

Workflow

  1. GitHub Actions triggers the application hourly.
  2. The app checks the configured day, hour and timezone and exits immediately if no job is due.
  3. The selected backend authenticates — OAuth for Spotify, browser-session credentials for YouTube Music, both reconstructed from CI secrets at runtime.
  4. Recent listening history is fetched and play frequencies are counted across a rolling window.
  5. Tracks crossing the repeat threshold are filtered against the existing library and the remainder are saved.
  6. On the weekly run, those favourites seed the platform's recommendation engine and the playlist is rebuilt from the results.
  7. Gemini generates a personalised summary from the week's data.
  8. Twilio delivers the summary and playlist link to WhatsApp.

Tech Stack

Python Spotify API (Spotipy) YouTube Music API (ytmusicapi) Google Gemini API Twilio WhatsApp Business API GitHub Actions cron

My Role

Designed and built the entire system — the platform abstraction unifying two separate API integrations, the auto-liking heuristic, the recommendation and playlist pipeline, the Gemini summarisation layer, WhatsApp delivery through Twilio, and the config-driven CI automation.

Description

A database-driven system for managing student academic records — students, subjects, marks and result processing — with role-based access control. It replaces manual result handling with a secure, scalable workflow built on a properly normalised schema.

Highlights

  • Normalised schema: designed a relational database for managing students, subjects and results.
  • Role-based authentication: separate Admin and Teacher access paths, with inactive users blocked rather than deleted.
  • Management modules: student records, subject handling and marks entry, each scoped to the right role.
  • Automated results: total, percentage, grade and pass/fail computed rather than entered by hand.
  • Data integrity: validation against maximum marks and prevention of duplicate entries.

Workflow

  1. A user signs in; credentials are validated and their role and active status checked before any dashboard loads.
  2. Admins manage the student roster and subject catalogue, including maximum and passing marks per subject.
  3. Teachers enter marks per student per subject, validated against the subject maximum and guarded against duplicates.
  4. The system computes totals, percentage, grade and pass/fail status from the recorded marks.
  5. Final results are surfaced to whichever roles are authorised to see them.

Tech Stack

Python MySQL Flask

My Role

Designed the database schema and built the authentication, management and result computation layers — keeping UI, logic and data cleanly separated.
